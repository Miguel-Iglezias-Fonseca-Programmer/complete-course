Desenvolvedor Web Certificado

A arte do Front-End me atacou de forma violenta no começo.
Para mim, que só havia aprendido a lógica no Visualg, foi
muito difícil aprender a usar HTML.
Mas, após um tempo, fui aprendendo os comandos de forma
que meus dedos só digitam o código sem pensar muito.
Aprendi a usar o CSS decorando os comandos mais comuns, a usar Flexbox e CSS Grid.
Ao completar este curso, sinto que saí mudado de várias formas...
Agora, deixo o meu mais carinhoso obrigado a todos que me
permitiram chegar até aqui. E agora, em meio aos versos, me despeço.
